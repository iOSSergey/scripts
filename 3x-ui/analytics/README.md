# Xray access live

`xray-access-live.py` — цветной просмотр подключений из Xray / 3x-ui access.log.
Нужны Python 3.8+ и системная команда `tail`, установка пакетов через pip не нужна.

```bash
# Последние 10 строк /usr/local/x-ui/access.log, затем новые записи
sudo ./xray-access-live.py

# Только новые записи из указанного файла; продолжает чтение после ротации
./xray-access-live.py /path/to/access.log -n 0

# Использование в pipeline (минус означает чтение stdin)
tail -F /usr/local/x-ui/access.log | ./xray-access-live.py -

# Фильтры можно комбинировать
./xray-access-live.py --user 'Ishina' --route lobasto-v6
./xray-access-live.py --route direct

# Последние 50 строк без дальнейшего наблюдения
./xray-access-live.py -n 50 --once
```

Пример вывода без ANSI-цветов:

```text
Natalie Android  [lobasto-v6]
Ishina iPhone Pro 5  [lobasto-v6]
Yaroslav Tarasov - Gleb Android  [direct]
```

Каждая запись занимает одну строку: только имя пользователя и исходящий маршрут.
Имя берётся целиком из `email`, включая пробелы; длинные имена не обрезаются.
Если имя отсутствует, выводится `—`.
Цвет пользователя постоянный; `direct` зелёный, остальные маршруты пурпурные,
`block` / `blocked` / `blackhole` красные.
Это поток событий, а не список активных сессий; повторные события сохраняются.

По умолчанию цвета включены только в терминале. `--color always` принудительно
включает цвета, `--color never` или `NO_COLOR=1` отключает автоматические цвета.
Старые флаги `--no-header` и `--one-line` принимаются для совместимости и ничего не меняют.
Вывод не буферизуется; остановка — `Ctrl+C`.

`--user` ищет подстроку без учёта регистра, `--route` требует точного совпадения.
Нераспознанные строки пропускаются.
Для stdin параметры `-n` и `--once` не применяются: поток читается до EOF.
При запуске с файлом `-n` применяется до фильтров. Для ротации используется
`tail -F`; его диагностические сообщения остаются в stderr.
