# Xray access live

`xray-access-live.py` — цветной просмотр подключений из Xray / 3x-ui access.log.
Нужны Python 3.8+ и системная команда `tail`, установка пакетов через pip не нужна.

```bash
# Последние 10 строк /usr/local/x-ui/access.log, затем новые записи
sudo ./xray-access-live.py

# Только новые записи из указанного файла; продолжает чтение после ротации
./xray-access-live.py /path/to/access.log -n 0

# Использование в pipeline (минус означает чтение stdin)
tail -F /usr/local/x-ui/access.log | ./xray-access-live.py -

# Фильтры можно комбинировать
./xray-access-live.py --user 'Ishina' --route lobasto-v6
./xray-access-live.py --route direct --one-line

# Последние 50 строк без дальнейшего наблюдения
./xray-access-live.py -n 50 --once
```

Пример вывода без ANSI-цветов:

```text
── 2026/09/25 ──
09:51:03.314954  Natalie Android  [lobasto-v6]
    TCP  95.24.156.231:21006 → i.instagram.com:443  ·  in: inbound-443
09:51:03.476708  Ishina iPhone Pro 5  [lobasto-v6]
    TCP  46.138.25.182:3839 → [2001:67c:4e8:f004::b]:443  ·  in: inbound-443
09:51:03.632832  Yaroslav Tarasov - Gleb Android  [lobasto-v6]
    UDP  91.79.36.14:27723 → 8.8.8.8:53  ·  in: inbound-443
```

Имя берётся целиком из `email`, включая пробелы. Слева от стрелки — адрес
и порт клиента, справа — назначение. TCP/UDP — протокол назначения;
`[lobasto-v6]` / `[direct]` — исходящий маршрут, `in:` — входящий обработчик.
Цвет пользователя постоянный; `direct` зелёный, остальные маршруты пурпурные,
`block` / `blocked` / `blackhole` и статус `REJECTED` красные.
Длинные имена и IPv6 не обрезаются. Время сохраняется как в исходном логе,
без изменения часового пояса. Это поток событий, а не список активных сессий.

По умолчанию цвета и заголовки включены только в терминале. При перенаправлении
вывода каждая запись содержит полную дату. `--color always` принудительно
включает цвета, `--color never` или `NO_COLOR=1` отключает автоматические цвета.
`--no-header` убирает заголовки, `--one-line` даёт плотный однострочный вывод.
Вывод не буферизуется; остановка — `Ctrl+C`.

`--user` ищет подстроку без учёта регистра, `--route` требует точного совпадения.
Нераспознанные строки всегда выводятся с меткой `UNPARSED`, даже при фильтрации,
чтобы не скрывать ошибки и неожиданные форматы лога.
Для stdin параметры `-n` и `--once` не применяются: поток читается до EOF.
При запуске с файлом `-n` применяется до фильтров. Для ротации используется
`tail -F`; его диагностические сообщения остаются в stderr.
